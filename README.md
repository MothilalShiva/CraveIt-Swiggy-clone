## 📌 Project Overview  

This project is a clone of the popular food delivery app **Swiggy**, built using **React.js**. It replicates key user-facing features such as browsing restaurants, viewing menus, managing the cart, and reviewing orders. It serves as a practical hands-on experience in frontend development, UI/UX, and state management.

---

## ✨ Features  

- 🍽️ **Restaurant Listing**  
  Browse and choose from a variety of available restaurants.

- 📋 **Menu Display**  
  View detailed menu items, pricing, and descriptions for each restaurant.

- 🛒 **Cart Management**  
  Add, update, and remove items from your cart dynamically.

- 🧾 **Order Summary**  
  Get a complete breakdown of items and pricing before placing an order.

- 📱 **Responsive Design**  
  Fully optimized for both desktop and mobile devices.

---

## 🧰 Technology Stack  

### 💻 Frontend:  
- React.js ⚛️  
- React Router 📍 (for navigation)  
- CSS 🎨 (custom styling)

### 🔄 State Management:  
- `useState` & `useEffect` hooks for local state management ⚙️

### 📦 Mock Data:  
- Static JavaScript file simulating restaurant and menu data 🗃️

## 🚀 Getting Started  

### Prerequisites  
- Node.js v14+  
- npm or yarn  

### Clone the Repository  
```bash
git clone https://github.com/MothilalShiva/swiggy-clone.git
cd swiggy-clone
npm install
```

### Start the App  
```bash
npm start
```

The app will be running on `http://localhost:3000`.
